# Code of conduct

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](CODE_OF_CONDUCT.vi.md)

This project expects professional, respectful, evidence-driven collaboration. Technical disagreement is welcome; personal attacks, harassment, credential disclosure, unauthorized voice-data sharing, and intentionally misleading benchmark claims are not.

When reporting a failure, focus on reproducible facts: revision, environment, command/request, sanitized logs, and expected versus observed behavior. Security-sensitive reports should follow [SECURITY.md](SECURITY.md).
